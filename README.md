# data-structures

A collection of data structure implementations written in C.

## Goals

- Implement common data structures from scratch in C
- Practice memory management, pointer handling, and API design
- Keep each structure self-contained and well-documented

## Build

If you want to run a test, you should go to the test file
that you want to run and then you you run the command
`make` to generate the executable `t` which can be runned
by executing `./t`
```bash
# example
cd test/test_hashmap
make
./t
```

## Status

Actively maintained — structures are added and refined over time (see commit history for recent changes like added tests, bug fixes, and documentation).
